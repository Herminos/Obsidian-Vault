# 考前速查与自测

以下为按大纲设计的自测，不是历年真题。先独立回答，再展开答案；需要推导时返回 [[电子电路技术/README|专题索引]]。

## 1. 最容易混用的条件

| 问题 | 先检查 |
|---|---|
| 二极管导通后输出多少 | 理想还是恒压降，电流方向是否满足假设 |
| BJT 能不能用 $I_C=\beta I_B$ | 先验证在放大区 |
| 放大倍数里的负载 | 直流是否被耦合电容隔开，交流是否并联进来 |
| 最大输出 | 是峰值、峰峰值还是有效值；截止与饱和哪边先到 |
| 比较器能否虚短 | 只在翻转临界点求阈值，平时由输入差决定状态 |
| 波形发生器的波形 | RC 充放电是指数线，恒流积分才是直线 |
| 整流系数 0.45／0.9／1.2 | 输入用有效值；电路类型和有无电容必须匹配 |
| 138／151 输出取反 | 看输出标记与使能条件，不靠器件名字猜 |
| 卡诺图的 X | 只能来自题目约束，不能把合法的 0 当 X |
| 计数器译码 M 或 M−1 | 异步清零还是同步清零／置数 |
| Verilog 是否异步复位 | 看敏感表，不只看变量叫不叫 reset |
| ROM／DAC 位序 | 地址最高位、数据实际接入 DAC 的高位还是低位 |

## 2. 模电自测

1. N 型半导体是否带负电？正偏 PN 结的耗尽层怎样变？
2. 稳压管输出等于 $U_Z$ 后，还要检查什么？
3. NPN 三端对地电位为 $V_C=6,V_B=1.7,V_E=1.0\,\mathrm V$，能否判断处于放大区？
4. 发射极充分旁路，$I_{CQ}=2\,\mathrm{mA}$、$R_C'=2\,\mathrm{k\Omega}$、$U_{CEQ}=3\,\mathrm V$、$U_{CE(sat)}=0.2\,\mathrm V$，最大输出幅值？
5. 反相滞回比较器输出 $\pm6\,\mathrm V$，同相端 $u_+=2+u_o/3$，两个阈值和跳转方向？
6. 对称 RC 矩形波，阈值 $\pm U_Z/3$，充放电电阻相同，周期？
7. MOSFET 在零栅压已导通，负栅压能截止，正常漏电流为正，属于哪种？
8. 某带通两侧斜率为 $+20,-20\,\mathrm{dB/dec}$，能说它是一阶吗？
9. 理想桥式整流无电容，二次电压 $10\,\mathrm V$ 有效值，输出平均电压、每管最大反压？
10. 7805 公共端为对地 2 V，输出对地多少？

<details>
<summary>展开模电答案</summary>

1. 整体电中性；正偏时耗尽层变窄。
2. 检查稳压电流上下限、功耗，以及输入／负载变化的最坏情况。
3. 发射结正偏约 0.7 V、集电结反偏，符合正常正向放大条件。
4. $\min(4,3-0.2)=2.8\,\mathrm V$，峰峰值 5.6 V。
5. 上阈值 4 V，下阈值 0 V；输入上升至 4 V 高变低，下降至 0 V 低变高。
6. $T=2RC\ln2$。
7. N 沟道耗尽型。
8. 不能；一阶高通和一阶低通级联形成的是二阶带通。
9. 平均 9 V，每管最大反压约 $10\sqrt2\,\mathrm V$。
10. 正常工作时 7 V；固定的是输出相对公共端的 5 V。

</details>

## 3. 数电自测

1. $(101101.101)_2$ 转十进制与十六进制。
2. $A,B,C$ 从高到低，写 $m_5,M_5$。
3. 四变量 $F=\sum m(0,2,8,10)$ 最简式？
4. 用 138 实现 $F=m_1+m_3+m_7$，后级用什么门？
5. 由四选一实现全加器和 S，A、B 作选择端，四个数据端接什么？
6. 两个同钟 D 触发器有 $D_0=\overline Q_0,D_1=Q_1\oplus Q_0$，现态 01，次态？
7. 161 用异步清零实现模 6，译码哪个状态？163 同步清零实现模 6 呢？
8. 用 $1\mathrm K\times4$ 芯片构成 $4\mathrm K\times8$，需几片、多少根总地址线？
9. `always @(posedge clk) if(!rst_n) q<=0;` 是同步还是异步？
10. 同一时钟块 `q1<=d; q2<=q1;`，q2 得到新 q1 还是旧 q1？
11. 8 位 DAC 的 LSB=0.02 V，输入 `01001101`，输出幅值？
12. 8 位 SAR，时钟 250 kHz，忽略额外开销的转换时间？
13. Flash ADC 为 8 位，需要几个门限比较器？10 kHz 带限输入采样频率应怎样选？
14. ROM 四位值 6 接 8 位 DAC 高四位，低四位接零，$U_{REF}=5\,\mathrm V$，标准反相输出？

<details>
<summary>展开数电答案</summary>

1. 45.625，$(2D.A)_{16}$。
2. $m_5=A\overline BC$，$M_5=\overline A+B+\overline C$。
3. $\overline B\,\overline D$。
4. 将低有效 $Y_1,Y_3,Y_7$ 送三输入与非门，并正确使能 138。
5. $C_{in},\overline{C_{in}},\overline{C_{in}},C_{in}$。
6. 10。两个次态都用边沿前的旧值。
7. 161 检测 6（0110）；163 检测 5（0101）。
8. 8 片，12 根总地址线；低 10 根片内寻址，高 2 根选 4 个字组。
9. 低有效同步复位；敏感表只有 clk。
10. 旧 q1。
11. 1.54 V。
12. $32\,\mathrm{\mu s}$。
13. 255 个；采样频率高于 20 kHz，并留实际滤波余量。
14. 八位码值 96，$U_o=-5\times96/256=-1.875\,\mathrm V$。

</details>

## 4. 最后一次闭卷检查

- [ ] 能独立画共射的直流、交流、微变三张图。
- [ ] 能对比较器分别代高、低输出求阈值，并带方向画曲线。
- [ ] 能区分方波的高电平时长与三角波上升时长。
- [ ] 能识别五类滤波器，说明阶数判断依据。
- [ ] 能按每半周电流路径分析整流故障。
- [ ] 能从文字列真值表并按指定器件画组合电路。
- [ ] 能按时钟连接分析同步／异步状态转移，检查无效态。
- [ ] 能列 160～163 功能差异，实际数出改进制电路的稳定状态数。
- [ ] 能算存储容量、芯片数和首末地址。
- [ ] 能从 Verilog 写出功能表、波形或状态图，而非只认模块名称。
- [ ] 能说明 DAC 输出符号、码权、分辨率约定与 ADC 转换流程。
