# 有源滤波器识别

> **大纲 6；模电习题 6-1～6-3 的类型与阶数识别。** 不要求传递函数推导和特性参数计算，原习题 6-3 中的推导部分按大纲跳过。课件第 7 章，习题册第 6 章。

## 1. 从任务判断滤波类型

| 类型 | 通带 | 阻带 | 典型任务 |
|---|---|---|---|
| 低通 LPF | 低频 | 高频 | 提取低于 2 kHz 信号，抑制 100 kHz 以上干扰 |
| 高通 HPF | 高频 | 低频、直流 | 去直流或慢变化漂移 |
| 带通 BPF | 一段中频 | 低频和高频 | 提取 1 kHz 附近有用信号 |
| 带阻 BEF／陷波 | 低频和高频 | 中间一段 | 抑制 50 Hz 工频干扰 |
| 全通 APF | 各频率幅值增益相同 | 没有幅度阻带 | 移相、延时 |

“抑制 50 Hz”通常选窄带带阻，不是把 50 Hz 以上或以下的全部信号删掉。“1 kHz 固定频率信号”选中心在 1 kHz 附近的带通。

## 2. 看电路：先做低频、高频极限

$$
Z_C=\frac{1}{j\omega C}
$$

1. $f\to0$，电容近似开路，检查输入是否能传到输出。
2. $f\to\infty$，电容近似短路，再检查传输路径、反馈路径。
3. 两端不通过而中间通过是带通；两端通过、中间抑制是带阻。
4. 结合电路中电容位置、反馈连接和幅频图判断，不能只凭“电容串联就是高通”。

运放输入接地、反馈路径变化时尤其要分析反馈，而不能只看输入支路。全通电路的低高频端都能通过，但相位不同。

## 3. 看幅频曲线判断阶数

在单个低通或高通的远端阻带，每个有效极点贡献约 $20\,\mathrm{dB/dec}$ 的幅频斜率：

- 一阶低通：高频端约 $-20\,\mathrm{dB/dec}$。
- 二阶低通：高频端约 $-40\,\mathrm{dB/dec}$。
- 一阶高通：低频端随频率升高约 $+20\,\mathrm{dB/dec}$。
- 二阶高通：低频端约 $+40\,\mathrm{dB/dec}$。

一阶高通与一阶低通级联可形成二阶带通，两侧斜率分别为 $+20$ 和 $-20\,\mathrm{dB/dec}$，不能据某一侧斜率就把整个带通称为一阶。

**阶数由有效独立储能过程决定。** 不能把电路所有电容直接数一遍：去耦、旁路电容未必参与目标滤波；极零抵消也可能降低有效阶数。课内典型一阶 RC、二阶有源电路优先按结构辨认。

## 4. 会说出的结构特点

- 一阶有源低通：RC 低通加运放，运放提供增益与隔离。
- 二阶有源低通：更陡的高频衰减，某些结构可出现峰值。
- 高通：直流不能通过。
- 带通：通带下限必须低于上限；常用低通与高通级联。
- 带阻：低通、高通输出适当相加，中间形成阻带；不能把任意低通、高通直接串联说成带阻。
- 全通：幅频近似平坦，相频随频率改变。

截止频率通常对应幅值降到通带幅值的 $1/\sqrt2$，即约 $-3\,\mathrm{dB}$；本章只作读图识别，不展开参数推导。
