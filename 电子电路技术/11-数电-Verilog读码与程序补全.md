# Verilog 读码与程序补全

> **大纲 16；数电习题 8-2～8-7，以及组合／时序 Verilog 课件。** 会从程序写功能表、波形和状态图，能补全基本程序。先按代码实际行为判断，不按模块名字猜功能。

## 1. 读程序的固定顺序

1. 看端口方向、位宽和位序，例如 `[7:0]` 中 7 是高位。
2. 找 `assign` 和各个 `always`：哪些是组合逻辑，哪些在边沿存储。
3. 列清复位、装载、使能的有效电平和优先级。
4. 用现态算次态，明确溢出截断、循环模数和非法态。
5. 组合逻辑逐行列真值表，时序逻辑逐事件画波形；有状态机则列全部状态与输入。

`wire` 通常由连续赋值或模块端口驱动；`reg` 表示可被过程赋值的变量，**不等于一定生成触发器**。完整赋值的 `always @*` 可生成纯组合逻辑；组合过程中某分支不赋值可能推断锁存器。

| 写法 | 含义／常见错误 |
|---|---|
| `assign y = a & b;` | 连续组合赋值 |
| `always @*` | 输入相关量变化时重算组合逻辑 |
| `always @(posedge clk)` | 上升沿时序逻辑；块内的复位是同步的 |
| `always @(posedge clk or negedge rst_n)` | 常见低有效异步复位描述，块内先判断 `!rst_n` |
| `4'b1010`、`8'h3F` | 明确位宽、进制的常量 |
| `{a,b}` | 拼接，a 在高位；不是相加 |
| `~a`／`!a` | 按位取反／逻辑非，结果位宽不同 |
| `a & b`／`a && b` | 按位与／逻辑与；单比特时才常有相同结果 |
| `&a` | 归约与，把所有位相与成一位 |
| `==`／`=`／`<=` | 相等比较／阻塞赋值／非阻塞赋值（按语境也可能是小于等于） |

`case` 要核对每种输入和 `default`。`case` 不是自动的优先编码器；普通 `case` 对每一位进行匹配。时序块一般使用 `<=`，组合块一般使用 `=`。

## 2. 阻塞与非阻塞：波形最容易丢分的位置

```verilog
always @(posedge clk) begin
    q1 = d;
    q2 = q1;
end
```

上述同一过程内立即顺序赋值，边沿后 q1、q2 都得到该边沿采到的 d，不构成两拍延迟。

```verilog
always @(posedge clk) begin
    q1 <= d;
    q2 <= q1;
end
```

非阻塞赋值先按旧值求右端，再安排更新：

$$
q_1^{n+1}=d^n,\qquad q_2^{n+1}=q_1^n
$$

这是两级寄存器。不同进程之间也不要依靠阻塞赋值的执行先后来传递同拍新值。

## 3. 习题 8-2：下降沿翻转，同步清零

原题 `negdge` 拼写有误，应为 `negedge`。按题意修正后：

```verilog
always @(negedge clk) begin
    if (rst) Q <= 1'b0;
    else     Q <= ~Q;
end
```

| 事件 | rst | Q 的变化 |
|---|---|---|
| clk 下降沿 | 1 | 变成 0 |
| clk 下降沿 | 0 | 翻转 |
| 无下降沿 | 任意 | 保持，即使 rst 中途变 1 |

**这是高有效同步清零**，因为敏感表只有时钟。初始 Q=1，逐个下降沿读 rst，即可画原题波形。若改成 `@(negedge clk or posedge rst)` 才是对应异步清零，不能把这种改动当成原题行为。

## 4. 习题 8-3：74LS192 双时钟加减计数器

CR 高有效异步清零，nLD 低有效异步置数；清零优先。CPu 上升沿计数加一时要求 CPd=1；CPd 上升沿减一时要求 CPu=1。正常 BCD 范围为 0～9。

原题通过下降沿记录方向 `Flag_U_D`：CPu 下降置 0，CPd 下降置 1。因此在两个时钟不重叠、满足器件正常时序的条件下，两个空分别可填：

```verilog
CPd && !Flag_U_D       // 加计数条件
CPu &&  Flag_U_D       // 减计数条件
```

终端输出低有效，其有效脉冲在对应时钟的低电平期间产生：

```verilog
assign nCO = ~((Q == 4'd9) && !CPu);
assign nBO = ~((Q == 4'd0) && !CPd);
```

加计数：9 后回 0；减计数：0 后回 9。并行装载顺序 `{D,C,B,A}`，D 为最高位。原题多时钟敏感表是对专用器件行为的教学描述，不能直接当作普通 FPGA 单时钟寄存器模板。

## 5. 习题 8-4：看清 load 的极性与加减方向

原题核心为：

```verilog
always @(posedge clk) begin
    if (!reset)    out = 8'h00;
    else if (load) out = data;
    else           out = out - 1;
end
```

功能：**8 位同步减法计数器**；reset 低有效同步清零，load 高有效同步装载，清零优先。无清零、装载时，0 的下一态为 255，正常计数模数 256。

不要照搬课件加法计数器中“load 低有效”的结论。原题仅对 out 赋值，没有用到更新后的 out 去更新其他寄存器；把三处 `=` 改成 `<=` 可使时序写法更规范且保持这里的功能。

## 6. 习题 8-5、8-6：位序、默认值及印刷问题

8-5 中 `temp={A,EN}`，EN 在最低位，只有 EN=1 时进入八种显式分支。由原代码实际读出的表是：

| A[2:0] | EN=1 时 Y[7:0] |
|---|---|
| 000 | 00000001 |
| 001 | 00010000 |
| 010 | 00000100 |
| 011 | 01000000 |
| 100 | 00000010 |
| 101 | 00100000 |
| 110 | 00001000 |
| 111 | 10000000 |

EN=0 时 Y=11111111。输出置一位置的索引是 `{A[0],A[1],A[2]}` 的数值；高低位顺序与普通二进制编号相反。**这段代码不等同于 74LS138**：使能方式、输出极性和位序都要按程序处理。

原题写成裸 `always case ...`，无事件等待会导致零时间反复执行，仿真不能正常推进；应改为 `always @*`，保留原分支内容。`wire [3:0] temp={A,EN};` 是网线声明连续赋值，可以成立。

8-6 是逆向一位有效编码示例：Y 的置一位索引 0～7 分别输出 `000,100,010,110,001,101,011,111`，同样反转位序。无匹配或多位为 1 时默认输出 000，不能自行改成优先编码。还需修正 `always @*` 与 `default: A=3'b000;` 的冒号。

大纲不把编码器作为独立考核重点；此处仅用于覆盖习题中的**程序阅读和纠错**，不展开专用编码器器件。

## 7. 习题 8-7：模 60 计数器参考答案

以下明确采用**上升沿、低有效异步复位**，状态是二进制整数 0～59，不是两位 BCD；题目若另给接口要求应随之修改。

```verilog
module mod60 (
    input wire clk,
    input wire rst_n,
    output reg [5:0] count
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)            count <= 6'd0;
        else if (count >= 6'd59) count <= 6'd0;
        else                   count <= count + 6'd1;
    end
endmodule
```

6 位可表示 0～63，足以容纳 60 态；`>=59` 还让 60～63 下一拍回 0。若只写 `==59`，也应另查越界态最终能否恢复。检查波形至少包含：复位在非时钟边沿生效、0→1、58→59→0、复位释放后等待下一上升沿。

如果要求十位／个位各为 BCD，应使用两个计数变量：个位到 9 回零并进位，十位到 5 且个位到 9 时同时回零。

## 8. 课件 Moore 状态机：程序变状态图

依据时序 Verilog 课件第 25～31 页，状态表为：

| 现态 | din=0 次态 | din=1 次态 | op |
|---|---|---|---|
| S0=00 | S0 | S1 | 0 |
| S1=01 | S2 | S1 | 1 |
| S2=10 | S3 | S2 | 0 |
| S3=11 | S3 | S0 | 0 |

op 只在 S1 为 1，所以是 Moore 型；每行画两条按 din 标注的箭头即可恢复状态图。`current_state <= next_state` 仅在上升沿执行，组合过程随状态或 din 变化重新计算。

原课件示例没有显式复位：画确定波形时应使用题目给出的初态；工程实现一般补复位。Mealy 型则应逐分支列“次态、输出”，输出可能在时钟边沿之间随输入改变。
