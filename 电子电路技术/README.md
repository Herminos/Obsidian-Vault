# 电子电路技术复习导航

本组笔记依据你提供的《电路与电子技术(2)复习大纲》三页内容，结合模电 7 份课件、RAR 中的数电课件及两册习题整理。按大纲 17 项要求合并为 12 篇专题，另附考前自测；公式使用标准 LaTeX，重点处保留原题电路截图。

**复习顺序遵循大纲：先做习题册，再按大纲看教材例题与课后题。** 做题卡住时回看相应专题的解题步骤，再遮住答案重做。这里的“重点／必会”由大纲要求决定，没有根据往年卷推断分值或出题概率。

## 明确的范围边界

- 模电 **3-5、7-2、7-5 不要求**；习题章号与课件不完全对应，以下表为准。
- MOSFET 不要求跨导、静态工作点和动态参数计算；滤波器不要求传递函数推导和特性参数计算。
- 数电卡诺图最高四变量，跳过五变量题 3-3(10)。编码器、显示译码电路不作独立专题，**74LS138 仍是重点**。
- Verilog 8-6 虽涉及编码，只作为程序阅读／纠错示例。大纲列有流水线 ADC，课件则有双积分；第 12 篇已分开说明，以并行比较和逐次逼近为主线。
- 习题中有 `negdge`、裸 `always`、`default` 缺冒号等问题；笔记明确标出原题行为与必要修正。

## 考前怎么用

第一轮按上表逐章做题并记录错因；第二轮只重做出错题，要求自己独立画图和写式；最后用 [[13-考前速查与自测]] 检查是否还混淆有效电平、位序、峰值／有效值与同步／异步。

教材原文未随资料提供，笔记不虚构教材页码。习题示例是据题图独立推导的学习参考，不称为官方答案；采用理想器件、恒压降、中频等近似时均说明条件。
