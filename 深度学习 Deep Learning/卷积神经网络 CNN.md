# 卷积神经网络 (Convolutional Neural Network, CNN)

**卷积神经网络 (CNN)** 是专门为处理网格结构数据（如图像）设计的神经网络架构。通过**感受野 (Receptive Field)** 和**参数共享 (Parameter Sharing)** 两大核心思想，CNN 大幅减少了参数量，成为图像识别领域的基础架构。

---

## 1. 图像分类与全连接网络的问题

### 1.1 图像作为张量

一张 RGB 彩色图像可以表示为一个三维**张量 (Tensor)**：

$$
\mathbf{X} \in \mathbb{R}^{H \times W \times C}
$$

其中 $H$ 为高度，$W$ 为宽度，$C=3$ 为通道数（RGB）。

分类任务中，输出是一个**独热向量 (One-Hot Vector)**，维度等于类别总数。例如 1000 类分类时，输出维度为 $1000$。

### 1.2 全连接网络为什么不行？

若输入为 $100 \times 100 \times 3 = 30{,}000$ 个像素，输出 1000 个类别，仅第一层就有：

$$
30{,}000 \times 1{,}000 = 3 \times 10^{7} \text{ 个参数}
$$

参数过多导致：
- **计算量巨大**，训练缓慢
- **严重过拟合**（参数量 >> 数据量）
- **忽略了图像的空间结构**（相邻像素关系被丢弃）

CNN 正是为了解决这些问题而设计的。

---

## 2. 感受野 (Receptive Field)

### 2.1 核心思想

与其让每个神经元看整张图，不如让每个神经元只**守备一个局部区域**，在这个小区域内寻找特征（如鸟嘴、眼睛等局部 Pattern）。

这个局部区域称为**感受野 (Receptive Field)**。

### 2.2 典型设置

| 参数 | 含义 | 典型值 |
|------|------|:--:|
| **Kernel Size** | 感受野的窗口大小 | $3 \times 3$ |
| **Stride** | 窗口每次滑动的步长 | $1$ 或 $2$ |
| **Padding** | 边缘补零的圈数 | $1$（same padding） |

- 感受野会覆盖**所有 Channel**（3 个 RGB 通道一起看）
- 不同感受野之间可以重叠（Stride < Kernel Size）
- 所有感受野拼在一起将**完整覆盖**整张图片

### 2.3 同一个感受野可以有多个神经元

一个感受野不只连接一个神经元——通常会有多个神经元守备**同一个**感受野，各自学习不同的特征（如一个检测边缘，一个检测纹理）。

---

## 3. 参数共享 (Parameter Sharing)

### 3.1 核心思想

同样的 Pattern 可能出现在图片的**不同位置**。例如，鸟嘴可能出现在左上角，也可能出现在右下角——检测鸟嘴的神经元参数应该是相同的。

**参数共享**：不同位置的感受野中，执行相同检测任务的神经元**共享同一组参数**。

### 3.2 限制

守备**同一个**感受野的多个神经元**不能**共享参数，否则它们的输出将完全相同，失去多样性。

---

## 4. 卷积层 (Convolutional Layer)

### 4.1 定义

**感受野 + 参数共享 = 卷积层 (Convolutional Layer)**

有卷积层的网络就是**卷积神经网络 (CNN)**。CNN 是为图像（网格数据）量身定做的架构。

### 4.2 从 Filter（滤波器）角度理解

每个 **Filter（滤波器 / 卷积核）** 在图片上滑动，对每个感受野做卷积运算（逐元素相乘再求和），输出一个特征值。

- 一个 Filter 扫完整张图 → 一张 **特征图 (Feature Map)**
- 多个 Filter → 多个 Feature Map → 构成一个新的「多通道图像」
- Filter 的数量 = 输出 Feature Map 的**通道数 (Channel)**

数学上，对于输入 $\mathbf{X}$ 和 Filter $\mathbf{K}$：

$$
(\mathbf{X} * \mathbf{K})_{i,j} = \sum_{m} \sum_{n} \sum_{c} \mathbf{X}_{i+m, j+n, c} \cdot \mathbf{K}_{m, n, c}
$$

### 4.3 Filter 大小不会限制更大 Pattern 的识别

单个 Filter 的感受野虽小（如 $3 \times 3$），但通过**堆叠多层卷积**，深层神经元可以看到更大的「有效感受野」：

```
第 1 层：看到 3×3 区域
第 2 层：看到 5×5 区域（通过组合第 1 层的输出）
第 3 层：看到 7×7 区域
...
```

浅层检测局部细节（边缘、角点），深层组合浅层特征识别更大的语义对象。

---

## 5. 池化 (Pooling)

### 5.1 定义与动机

**池化 (Pooling)** 对 Feature Map 进行下采样，在每个局部窗口内取一个代表值。

### 5.2 最大池化 (Max Pooling)

最常用的池化方式——在窗口内取**最大值**：

$$
\text{Pooling}_{i,j} = \max_{(m,n) \in \text{window}} \mathbf{X}_{i+m, j+n}
$$

- 典型参数：$2 \times 2$ 窗口，Stride $= 2$（尺寸减半）
- 卷积层和池化层**交替使用**，逐步压缩空间维度

### 5.3 池化的优缺点

| 优势 | 劣势 |
|------|------|
| 显著**减少运算量** | **丢弃精细的空间信息** |
| 提供**平移不变性** | 对小物体定位不友好 |
| 减少过拟合 | — |

> 🔮 **趋势：** 随着 GPU 算力的增长，现代 CNN 架构越来越**少用池化**——直接用 Stride $> 1$ 的卷积替代下采样，保留更多细节信息。

---

## 6. 经典 CNN 图像识别流程

```
输入图片
  ↓
[卷积层 Convolution] → 提取特征，保持空间结构
  ↓
[池化层 Pooling]     → 下采样，降低维度
  ↓
[卷积层 Convolution] → 更高层特征
  ↓
[池化层 Pooling]
  ↓
[展平 Flatten]       → 将 feature map 拉成向量
  ↓
[全连接层 FC]        → 综合所有特征进行分类
  ↓
[Softmax]            → 输出各类别概率
```

## 7. 案例：AlphaGo 中的 CNN

AlphaGo 用 CNN 处理围棋棋盘，输入为 $19 \times 19$ 的张量（棋盘大小），输出为落子坐标。

### 7.1 为什么用 CNN？

- 围棋中的**局部 Pattern**（如「虎口」、「打劫」）很重要
- 同样的 Pattern 会出现在**棋盘不同位置** → 参数共享天然适合

### 7.2 AlphaGo 的输入通道（48 个 Channel）

| 通道数 | 内容 |
|:--:|------|
| 3 | 基础棋盘状态（黑子 / 白子 / 空） |
| 1 | 当前轮到哪方落子 |
| 2 | 历史落子记录 |
| 42 | 围棋专业概念特征（气、眼、征子等） |

### 7.3 AlphaGo 为什么不用 Pooling？

围棋需要**精细的落子判断**，Pooling 会丢弃关键位置信息。因此 AlphaGo 舍弃了 Pooling 层。

## 8. CNN 在其他领域的应用

虽然 CNN 最初为图像设计，但其局部特征提取和参数共享的思想也适用于其他领域：

- **语音识别**：频谱图可以看作「单通道图像」，CNN 捕捉局部频率 Pattern
- **自然语言处理 (NLP)**：文本的词向量序列也可以用一维卷积捕捉局部 n-gram 特征

---

## 9. CNN 的局限性

### 9.1 无法处理缩放和旋转

CNN 本身**不具备尺度不变性和旋转不变性**。一个放大的鸟和缩小的鸟在特征层面完全不同，CNN 无法自动建立关联。

**解决方案：**
- **数据增强 (Data Augmentation)**：训练时随机缩放、旋转图片，让模型见过各种变换
- **空间变换网络 (Spatial Transformer Layer)**：在网络中插入一个可学习的空间变换模块，自动将输入对齐到规范姿态

### 9.2 空间变换网络 (Spatial Transformer)

空间变换网络（不在本课程重点）的核心思想是在卷积之前对输入做可微分的空间变换（平移、旋转、缩放），使得后续 CNN 可以处理未对齐的图像。变换参数通过网络自身学习得到。

---

## 10. 关键结论 (Key Takeaways)

- **感受野 + 参数共享 = 卷积层**，两个设计使 CNN 大幅减少参数、保留空间结构
- CNN 本质上是**影像专用**架构，利用图像的局部相关性和平移等变性
- **Filter → Feature Map**：每个 Filter 扫描整个图像，产出一张特征图
- **多层堆叠**使深层神经元获得更大的有效感受野
- **Pooling** 曾经是标配，现代趋势是逐步减少使用，保留更多细节
- **AlphaGo** 是 CNN 在非图像领域的经典应用，48 通道输入 + 无 Pooling
- CNN 的**缩放/旋转局限**可通过数据增强或 Spatial Transformer 缓解
