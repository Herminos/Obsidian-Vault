# 过拟合 (Overfitting)

## 1. 定义

**过拟合 (Overfitting)** 指模型在训练数据上表现很好，但在未见过的测试数据上表现很差的现象。这意味着模型**记住了训练数据中的噪声和细节**，而非学习到可泛化的模式。

## 2. 数学描述

设 $L_{\text{train}}$ 为训练损失，$L_{\text{test}}$ 为测试损失：

$$
L_{\text{train}} \ll L_{\text{test}}
$$

即训练误差远小于测试误差（泛化差距很大）。

## 3. 为什么会发生过拟合？

- **模型过于灵活**：参数量远多于数据量，模型有足够自由度去「记住」每个样本
- **训练数据不足**：数据无法覆盖真实的整体分布
- **噪声记忆**：模型把数据中的随机噪声当成了真实信号来学习
- **训练时间过长**：持续训练使得模型逐步拟合噪声

可以这样直观理解：一个灵活度很高的模型，在训练数据未覆盖的区域会「自由发挥 (freestyle)」，产生不可预测的输出。

## 4. 解决方法

### 4.1 增加训练数据 (More Training Data)

最根本的解决方案。更多数据 → 更好的分布覆盖 → 压缩自由发挥空间。

### 4.2 数据增强 (Data Augmentation)

当无法获取更多真实数据时，基于已有数据创造变体：

- **图像**：翻转、旋转、缩放、裁剪、色彩抖动
- **文本**：同义词替换、回译 (Back-translation)
- **语音**：加噪、变速、音调变换

### 4.3 约束模型 (Constraining the Model)

| 方法 | 原理 |
|------|------|
| **减少参数量** | 降低模型复杂度，使其难以记住噪声 |
| **参数共享** | 如 CNN 卷积核共享权重，减少有效自由度 |
| **[[正则化 Regularization]]** | 在损失函数中加入对参数大小的惩罚 |
| **早停 (Early Stopping)** | 在验证损失开始回升前停止训练 |
| **丢弃法 (Dropout)** | 训练时随机丢弃神经元，防止共适应 |

### 4.4 集成方法 (Ensemble)

训练多个模型并对它们的输出取平均，可以降低方差、缓解过拟合。但代价是计算成本的增加。

## 5. 与欠拟合的对比

| | 过拟合 (Overfitting) | 欠拟合 (Underfitting) |
|------|------|------|
| **训练损失** | 很小 | 很大 |
| **测试损失** | 远大于训练损失 | 也很大 |
| **原因** | 模型太复杂 | 模型太简单 |
| **解决** | 约束模型 / 增加数据 | 增加模型复杂度 |

## 6. 偏差-方差视角

在偏差-方差分解中，过拟合对应**高方差 (High Variance)**：

$$
\text{期望测试误差} = (\text{Bias})^{2} + \text{Variance} + \text{Irreducible Error}
$$

- 高偏差 → 欠拟合（模型太简单）
- 高方差 → 过拟合（模型太复杂）
- 最优模型需要在两者之间找到平衡
