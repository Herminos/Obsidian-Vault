# 深度学习 (Deep Learning)

## 1. 定义

**深度学习 (Deep Learning)** 是机器学习的一个子领域，使用包含**多个隐藏层**的**神经网络 (Neural Network)** 来学习数据的层次化表示。这里的「深」指的是网络的**层数多**。

## 2. 为什么需要「深」？

### 2.1 层次化特征学习

深度网络的每一层学习不同抽象级别的特征：

```
输入像素 → 边缘 → 纹理 → 部件 → 物体
（浅层）                           （深层）
```

- **浅层**：学习低级特征（边缘、颜色、梯度方向）
- **中层**：组合为中级特征（纹理、形状、部件）
- **深层**：组合为高级语义特征（人脸、汽车、猫）

这种层次化表示使深度网络能够用较少的参数表示复杂的函数。

### 2.2 参数效率

理论上，一个单隐藏层的网络已经能够逼近任意连续函数（通用逼近定理）。但实践中，**深度网络远比宽而浅的网络参数效率更高**：

- 宽而浅：可能需要指数级数量的神经元
- 深而窄：可以用多项式数量的神经元达到相同效果

这类似于数字电路：深层组合（$n$ 层）可以指数级地增加表达能力。

## 3. 深度学习的三要素

### 3.1 数据 (Data)

深度学习是数据驱动的：
- 需要**大规模标注数据**来训练深层网络
- 数据质量和多样性直接影响模型性能
- 数据增强是提高数据效率的重要手段

### 3.2 算力 (Compute)

- **GPU / TPU** 的大规模并行计算是深度学习复兴的关键驱动力
- 分布式训练使得训练超大规模模型成为可能
- 硬件进步 → 更大更深的模型 → 更强的性能

### 3.3 算法 (Algorithm)

关键算法进展：
- **反向传播 (Backpropagation)**：高效计算梯度
- **ReLU 激活函数**：缓解梯度消失
- **批归一化 (Batch Normalization)**：加速训练、稳定收敛
- **残差连接 (Residual Connection)**：使得训练数百层网络成为可能
- **Adam / SGD 变体**：更好的优化器
- **预训练 + 微调**：迁移学习范式

## 4. 主要架构类型

| 架构 | 适用领域 | 核心思想 | 代表模型 |
|------|------|------|------|
| **全连接网络 (MLP)** | 通用 | 每层全连接 | — |
| **卷积神经网络 (CNN)** | 图像 | 局部感受野 + 参数共享 | ResNet, VGG |
| **循环神经网络 (RNN)** | 序列 | 隐藏状态携带时序信息 | LSTM, GRU |
| **Transformer** | NLP / 多模态 | 自注意力机制 | GPT, BERT, ViT |
| **生成对抗网络 (GAN)** | 生成 | 生成器 vs 判别器博弈 | StyleGAN |
| **扩散模型 (Diffusion)** | 生成 | 逐步加噪 → 去噪 | Stable Diffusion |
| **图神经网络 (GNN)** | 图数据 | 邻居聚合 | GCN, GAT |

## 5. 训练深层网络的挑战

### 5.1 梯度消失/爆炸 (Vanishing/Exploding Gradient)

- 深度网络中梯度通过链式法则逐层相乘传播
- 若每层梯度 $< 1$ → **梯度消失**（浅层几乎不更新）
- 若每层梯度 $> 1$ → **梯度爆炸**（参数更新过大）

**解决方案：**
- ReLU 缓解梯度消失
- 批归一化 (Batch Normalization) 稳定激活值分布
- 残差连接 (Residual Connections) 提供梯度高速通道
- 梯度裁剪 (Gradient Clipping) 防止爆炸

### 5.2 过拟合

深层网络参数量巨大，容易过拟合。解决方案见 [[过拟合 Overfitting]]。

### 5.3 计算资源

训练大规模深层网络需要大量 GPU 和时间。通过分布式训练和混合精度训练来加速。

## 6. 迁移学习 (Transfer Learning)

深度学习的重要范式：由于从头训练深层网络昂贵且需要大量数据，实践中常在**大规模预训练模型**的基础上进行微调：

1. **预训练 (Pre-training)**：在大规模通用数据集上训练模型（如 ImageNet、大规模语料）
2. **微调 (Fine-tuning)**：在目标任务的小数据集上微调模型参数

这使得深度学习在数据稀缺的任务上也能取得良好性能。

## 7. 深度学习 vs 传统机器学习

| 方面 | 传统 ML | 深度学习 |
|------|------|------|
| **特征工程** | 需要人工设计 | 自动学习 |
| **数据需求** | 中等 | 大规模 |
| **可解释性** | 较好 | 较差（「黑箱」） |
| **计算资源** | CPU 即可 | 需要 GPU |
| **性能上限** | 有限 | 随数据/算力持续提升 |
