# 模型偏差 (Model Bias)

## 1. 定义

在机器学习中，**模型偏差 (Model Bias)** 有两个含义，需要区分上下文理解：

### 1.1 模型能力的偏差（本课程常用含义）

指**模型本身表达能力不足**，无法拟合训练数据的复杂分布。此时无论怎样优化参数，模型都无法在训练数据上获得低损失。

### 1.2 统计学中的偏差（Bias-Variance 分解）

指预测值的期望与真实值之间的系统性偏离：

$$
\text{Bias} = \mathbb{E}[\hat{f}(x)] - f(x)
$$

其中 $\hat{f}$ 是学习到的模型，$f$ 是真实函数。

## 2. 模型偏差的症状

- 训练损失 $L_{\text{train}}$ **一直很高**，无法降低
- 增加训练数据量也**无济于事**（模型本身就无法拟合）
- 增加训练轮次也无法改善

## 3. 根本原因

模型族（Model Family）的假设空间太小，真实的最优函数不在模型能够表示的集合内。

例如：真实数据服从二次曲线 $y = x^{2}$，但你只用线性模型 $y = wx + b$ 去拟合——无论 $w$ 和 $b$ 取什么值，都无法精确拟合抛物线。

## 4. 解决方案

| 方法 | 说明 |
|------|------|
| **增加特征 (More Features)** | 给模型更多输入信息 |
| **增加层数 / 神经元数** | 提高模型的表示能力 |
| **换用更灵活的架构** | 如从线性模型换为神经网络 |
| **引入非线性** | 添加[[激活函数 Activation Function]]，使模型能表示非线性模式 |
| **减少正则化约束** | 若正则化过度，会限制模型表达能力 |

## 5. 与过拟合的对比

| | 模型偏差 (Model Bias) | 过拟合 (Overfitting) |
|------|------|------|
| **训练损失** | 很大 | 很小 |
| **测试损失** | 很大 | 很大 |
| **根本原因** | 模型太简单 | 模型太复杂 |
| **解决方案** | 增加模型复杂度 | 约束模型 / 增加数据 |
| **增加数据有用吗** | ❌ 无用 | ✅ 有用 |

## 6. 与优化问题的区分

训练损失大有两种可能：模型偏差 或 优化问题。如何区分？

- 尝试使用**更大的模型**（更多层、更多神经元）
- 若训练损失降下来了 → 原模型存在模型偏差
- 若训练损失反而**更高** → 那是优化问题（更深的模型表达能力更强，不应更差）
